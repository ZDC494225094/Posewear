# 创作与素材功能验收

## 启用改动

服务端改动需要重启 Node 进程，再对浏览器执行强制刷新。地址以 `.env` 的 `PORT` 和启动日志为准；本次本机配置是 `http://127.0.0.1:3100`。重启前先确认没有正在生成的任务。

1.2.0 含数据库迁移 3 和 4，启动时自动执行；迁移 4 给作品记录镜头和真实感设置，并在职业服装下新增 6 个小类。新建的 JS 模块和测试文件应与其他改动一并交付，不要只复制已修改的旧文件。

## 页面入口

| 功能 | 入口 | 验收点 |
| --- | --- | --- |
| 创作记录卡片大小 | `/studio`、`/works` | 小、中、大实际改变布局，刷新后保留；方向键可切换大小。窄屏优先保证图片与按钮不溢出。 |
| 统一滚动条 | 全站及详情弹窗 | 页面、设置面板、弹窗使用统一样式；长内容可滚动。 |
| 人物历史选择 | 创作台 → 选择人物 | 上传照片、我的照片、我的作品三个入口；作品中的真人属性不可自行绕过。 |
| 虚拟人审核 | `/admin/virtual-persons` | 待审、通过、驳回及驳回原因；侧栏显示待审数量。 |
| 隐藏与收藏 | `/works` | 隐藏后从其他个人列表移除，可在“已隐藏”找回；收藏可取消。隐藏不等于取消公开。 |
| 首页真实组合 | 首页 | 姿势、服装与成品来自同一条成功且允许公开的生成记录。 |
| 素材任务与记录 | `/my-assets/jobs`、`/admin/asset-jobs` | 按状态、类型筛选；后台另有平台/用户归属筛选；点击结果查看详情。素材库仅显示任务提示，不堆放任务卡片。 |
| 作品详情与再次创作 | 我的作品 → 图片详情 | 显示姿势、服装、人物、场景与物品；按钮可达且可操作，带回参考和参数。 |
| 场景与物品 | 用户/后台素材库、分类管理 | 支持列表、分类、生成、后台上传、编辑、审核及上/下架；创作时场景图优先于文字场景，物品最多 3 件。 |
| 素材计费与模板 | `/admin/asset-settings` | 四类素材分别设置消耗；场景、物品各有文字及参考图生成模板，保存后服务端生效。 |
| 参考图排版 | `/studio` | 姿势、服装、人物一行，标题不换行、长编号省略；场景和物品在「更多参考」里，收起时提示已选内容。 |
| 卡片统一高度 | `/studio`、`/works` | 同一档大小的卡片高度一致，图片区固定 3:4；多张图拼在同一区域，右下角显示张数。 |
| 可缩放原图 | 作品详情、素材库详情 | 点详情里的图片打开原图；滚轮或双指缩放、拖动、双击在适应和 1:1 之间切换，Esc 关闭。 |
| 素材创作 | `/studio/assets` | 选大类、勾小类、按性别/季节/时段细分并加自定义细分；预览每一行；生成后右侧显示进度和结果。重复行、超过上限、含关闭分类时整批不提交。 |
| 镜头与真实感 | `/studio`、`/admin/generation` | 镜头预设可在后台编辑；选镜头或打开真实感后，提示词追加对应的一行，不选时与原来一致。 |

## 普通用户虚拟人闭环

1. 在创作台声明并上传成年虚拟人形象，状态为“审核中”，不能立即使用。
2. 管理员在“虚拟人审核”查看原图，选择通过或填写原因后驳回。
3. 用户在“我的照片”刷新审核状态。被驳回的可查看原因、重新声明申请；通过的可直接选用。
4. 通过的虚拟人及未使用真人照片的历史作品，不受真人照片专属的搭配、公开限制；平台通用内容安全和素材权限仍然生效。
5. 使用真人照片的作品仍不可公开，也不能通过选取其历史图片绕过限制。

## 参考图与隐私边界

- 本人的作品详情可以查看并复用尚未过期、未删除的上传服装及人物；过期/删除后给出重新选择提示，不恢复已清理的文件。
- 公开作品不泄露人物或自定义服装的上传 ID、原图地址。素材生成记录、原始参考和内部提示词只允许作者、管理员查看；已公开素材的名称、分类及关键词仍随素材展示。
- 点击素材或广场详情中的创作入口后应关闭旧弹窗，避免遮挡创作台。

## 自动验证

运行 `npm test` 和 `npm run check`。`test/creation-workflow.test.js` 采用临时数据库与本地假模型接口，验证普通用户虚拟人审核、私有参考复用/权限、场景物品生成与审核、后台上传与分类、隐藏收藏和首页对应关系。

自动验证不消耗真实模型额度，也不能证明人物相似度、姿势还原、场景还原或佩戴物品的视觉质量。这些需要授权后另做真实出图验收。`test/batch-camera.test.js` 验证批量创作和镜头提示词。

2026-10-31 做过一次真实对比：同一组姿势和服装，默认设置与「85mm 人像 + 真实感增强」各生成一张（标准画质，每张约 $0.08）。后者光线更柔和自然、皮肤和布料质感更接近实拍，前者更亮、更像精修图。
